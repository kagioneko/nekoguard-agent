Response Protocols

Gemini decides. You execute.

⚡
CAT Protocol
🔴 Active Breach — attacker is in right now
  • 🤖
    Agent: Block IPs via iptables
  • 🤖
    Agent: SSH in, collect logs, scan credentials
  • ✅
    You: Revoke exposed API keys
  • ✅
    You: Remove backdoor SSH keys & cron jobs
  • ✅
    You: Lock down at provider level

ABC Protocol
🟡 Past Breach — they're gone, assess damage
  • ✅
    Revoke all exposed credentials
  • ✅
    Audit OAuth connected apps
  • ✅
    Rotate passwords & SSH keys
  • ✅
    IP restriction + server hardening
